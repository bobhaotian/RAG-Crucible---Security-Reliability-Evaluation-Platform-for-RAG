# Helios TD-50 troubleshooting runbook

This runbook covers the most common error codes reported by the TD-50 tunnel inspection crawler. Always check the unit's event log in Fleet Manager before replacing hardware.

## E-410

Error code E-410 on the TD-50 indicates a track tension fault. To resolve it, adjust the track tensioner to specification. If the error persists after two attempts, open a support ticket and attach the diagnostic bundle exported from Fleet Manager.

## E-415

Error code E-415 on the TD-50 indicates a gas sensor saturation event. To resolve it, ventilate the area and zero the sensor. If the error persists after two attempts, open a support ticket and attach the diagnostic bundle exported from Fleet Manager.
