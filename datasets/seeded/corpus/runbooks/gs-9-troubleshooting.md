# Helios GS-9 troubleshooting runbook

This runbook covers the most common error codes reported by the GS-9 gas detection station. Always check the unit's event log in Fleet Manager before replacing hardware.

## E-520

Error code E-520 on the GS-9 indicates a sensor cell end-of-life warning. To resolve it, replace the electrochemical cell. If the error persists after two attempts, open a support ticket and attach the diagnostic bundle exported from Fleet Manager.

## E-523

Error code E-523 on the GS-9 indicates a heartbeat link timeout. To resolve it, check the LTE antenna and signal strength. If the error persists after two attempts, open a support ticket and attach the diagnostic bundle exported from Fleet Manager.
